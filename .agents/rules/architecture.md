# KaamSaathi Architecture Rules

1. **Layered Decoupling**:
   - Frontend must only access backend functionality through typed client services in `src/services/` using `VITE_API_BASE_URL`.
   - Backend routes must delegate business logic to service layers; never place raw database queries inside route handlers.
2. **Deterministic Financial Math**:
   - Monetary computations must never be generated by LLMs or floating-point division.
   - Use Pydantic `Decimal` with 2 decimal places on the backend and integer/fixed precision arithmetic on the client.
3. **Confirmed State Transitions**:
   - All financial mutations (creating jobs, modifying balances, recording payments) require explicit confirmation before persistence.
4. **Offline First Resilience**:
   - The application must gracefully degrade to local storage demo mode if backend or network connectivity is interrupted.
